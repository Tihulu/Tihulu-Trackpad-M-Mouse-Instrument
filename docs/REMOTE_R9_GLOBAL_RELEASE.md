# R9 release my controls
Adds a persistent mobile release button, separate from disconnect. Freezes activation, cancels unsent gestures and permission epochs, disables all local surfaces, preserves sent/pending owner knowledge and sends only necessary existing scoped releases via the one-ACK scheduler. No MIDI global panic, no other-device eviction, no automatic rearm. Completion requires all necessary ACKs; if not completed in 350ms close, earlier individual limits unchanged. No claim of actual MIDI/audio output. Four new browser scenarios; 55/55 V8 shim callbacks passed, native CI and physical pending. Stable unchanged.
