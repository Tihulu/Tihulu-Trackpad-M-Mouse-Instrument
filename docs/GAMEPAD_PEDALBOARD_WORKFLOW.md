Ten routes: A/B/X/Y/RB toggle (CC80/81/82/83/85), LB hold (CC84), LT continuous CC74, RT hold sustain (CC64), LS X bend, RS Y expression CC11. These are illustrative targets, not automatic effect/plugin assignments. In Logic select the TIHULU Instrument Builder port and target channel, learn the plug-in's absolute on/off parameter from the emitted MIDI CC. MIDI output must be enabled; no feedback from DAW or effect DSP is added.

Only the selected controller's draft map is replaced; populated maps require confirmation against the captured draft, and conflicting shared targets or capacity fail atomically. Other slots and devices, saved mapping, and stable install remain unchanged. Advanced Routes exposes pedal mode, channel, CC and threshold/hysteresis without incompatible analog response controls. Explicit conversion to an ordinary route remains possible.
