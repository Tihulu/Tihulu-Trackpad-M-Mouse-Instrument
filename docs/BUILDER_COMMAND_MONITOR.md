# Bounded Builder monitor publication
The command monitor used to publish an ObservableObject mutation for every attempted MIDI command, then publish again on trimming. Fan-out and release bursts now deliver in the same synchronous order, keep the attempted prefix including a failed command, and publish one newest-first display update capped at 24. Empty batches do nothing. No extra timer, audio queue, MIDI batching, delivery retry change or safety deadline relaxation. Two pure display history tests authored. UI CPU reduction not measured; native CI and real DAW acceptance pending. Stable untouched.
