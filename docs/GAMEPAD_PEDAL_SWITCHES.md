# Xbox Hold / Toggle effect pedals

Base #152 exact head 98e7696c34671096b1c7c864789facfcb6934b6c, CI run 45533489254 PASS.

In Builder > Xbox / Gamepad custom control map choose a slot and button or LT/RT, then Effect pedal / switch. Hold sends absolute CC 127 while pressed and 0 on release; Toggle changes between 127 and 0 on new presses. Trigger thresholds use the existing per-route hysteresis. Sustain CC64 is an optional target. Sticks retain continuous mappings. CC80/81/82 are example assignable numbers, not automatic drive or distortion destinations. In Logic learn the desired plugin parameter from the TIHULU Instrument Builder MIDI port and selected channel; use absolute 0/127 behavior rather than a second DAW toggle transformation. MIDI output must be enabled for the chosen controller. No plugin audio processing or feedback synchronization is added. The initial local latch is off, not a query of existing DAW state.

Optional Codable route mode defaults to nil for older patches. Copy/export preserves pedal mode but not live latch. Existing ordinary notes, chord, analog control and legacy sustain behavior remain. Explicit pedal assignment uses default calibration and no continuous response. Separate physical press state and session-owned latched contributions prevent repeated poll/callback snapshots from retriggering. Binary CC targets reconcile with OR semantics; different analog and switch mappings to the same CC are rejected. Other sustain owners continue holding sustain when one owner releases. Disconnect, explicit release, watchdog expiry and panic clear the relevant ownership; existing Builder delivery ledger handles actual MIDI cleanup and errors. The direct router does not guarantee receiver state after failed sends or manual external plugin changes. Local haptic output is not a distortion effect processor. Reserved configuration CCs and persistent gain CC7/11 are not admitted as binary effect switches.
