# Touch Instrument — Drums / Trackpad Haptic multi-finger regression

User report: Independent Surface Instruments & Outputs > Force Touch Trackpad > Drums > Trackpad Haptic does not play multiple fingers. Prior renderer already enumerates all native contacts and tracks independent contact IDs, but sends each pending strike to the same physical actuator consecutively during one 18 ms render tick. This can mask earlier hits. Source-level finding, not a measured physical root cause.

Candidate tracks per-contact down edges and rearms on lift, bounds pending strikes to 16, expires strikes at 40 ms, and mixes valid recent hits into one actuator submission. Round-robin tone allocation, exact-frequency merge, maximum original level instead of additive gain, and existing six-tone/duration/frequency safety policy. A single valid strike retains its waveform. MIDI drum ownership and send cadence unchanged. No new driver, runtime or timer. UI labels local haptic drums correctly, explains Touch trigger and distinguishes MIDI Multi Touch from the local finger path.

Evidence: exact Git blob hashes for HapticTypes.swift (95c8c7705e401e936288e0c258407289d1a4d958), DrumHapticMixer.swift (26b81135d14cad0b0d25b5bb57ee4c78d7f18629), DrumHapticStrikeBuffer.swift (74a793721543d40d57b55550b9c64c93030865ff) matched locally. Compiled with Swift 6.2.1 Linux and executed an isolated probe: PASS 2,012 assertions, including 2,000 isolated strikes in 1,000 paired cycles, three concurrent strike waveforms, held finger plus re-strike, stale expiry, reset, finite validation and tone budget. Five repository Swift Testing scenarios authored; full candidate CI pending. Probe uses synthetic drum frames, not physical measurements or the actual drum voice timbres.

Physical acceptance remains open: play Kick + Hat, Kick + Snare + Hat, hold one finger while rapidly retriggering another, alternate rolls, Touch vs Press trigger, Both MIDI/haptics, Stop/restart, and rapid simultaneous same-pad hits. Verify preview sees each finger; compare DAW event log and physical waveform. Same-frequency strikes can merge and the six-tone motor budget cannot independently reproduce arbitrary simultaneous samples. Adjacent render ticks may still interrupt prior physical waveforms. No claim of full audio-drum equivalence or verified fix on the user's Mac. Stable untouched.
