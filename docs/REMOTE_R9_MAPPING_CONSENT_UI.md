# R9 Mac invitation consent

Adds a one-invitation, default-off MIDI destination disclosure toggle in the existing Remote TLS panel. Explicit consent is captured before clearing prior invitation state and passed through StudioController to the existing bridge/runtime consent binding. The checkbox resets on creation, cancellation, expiry, source change, disappearance or listener stop. The generated invitation displays the actual disclosure setting. Consent cannot be edited after issuance; cancel/reissue, or disconnect an already admitted peer. Previously disclosed information cannot be recalled. Local diagnostic remains default-off. No persisted consent, new network route or secret in QR. Two additional core regression scenarios for cancellation, expiry, reissue and distinct admitted peers. Native macOS UI and CI pending; no physical verification. Custom labels remain a separate feature. Stable untouched.
