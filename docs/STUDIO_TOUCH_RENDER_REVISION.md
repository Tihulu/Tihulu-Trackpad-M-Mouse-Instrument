# Touch render configuration fence
Add a separate render revision to snapshots, checked inside the existing source submission fence immediately before driver play. Changing config or releasing sustain drains in-flight submissions after releasing the state lock. Clear live, sustained, and pending drum states on non-volume configuration changes, including output route changes. Volume-only changes keep held states; old-level snapshot submissions are rejected. A rejected or failed driver submission no longer reports success to drum scheduling. Existing driver frame already submitted may sound for its bounded duration; drain is not a hardware stop. Conservative mapping changes may interrupt held notes; new input is required. One pure concurrent drain test and one native configuration test authored. Native integration and hardware pending. Stable unchanged.
