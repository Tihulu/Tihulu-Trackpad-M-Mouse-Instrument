# R7b — browser piano

Two overlapping 13-key chromatic views (C3–C4 and C4–C5) with conventional white/black key layout, pointer capture, keyboard Space/Enter hold, independent momentary sustain, explicit enable and Release keys & pedal. Octave controls are locked until held keys/pedal, queued snapshots and outstanding piano ACKs are cleared. Each owner retains its original logical key. Scale/root selection highlights the default pitch classes only; it does not quantize, remap, or send MIDI. Labels assume the default Mac mapping.

The host preset appends missing 25 key + sustain routes, preserving existing routes and validating the 64-route cap. Browser requires mapped keys, not arbitrary client MIDI. Separate bounded ordered piano queue (8 transitions, 150 ms age limit), 25 ms normal edge interval, 50 ms held refresh, independent 350 ms host deadline, shared one-ACK scheduler. Emergency zero clears queued piano edges without releasing drum/motion owners. On backlog or lifecycle fault, disconnect releases all owners. No pressure inference, glissando gesture, arbitrary octave transpose, or actual acoustic audio. Real phone latency, readability and DAW sustain behavior remain HOLD. Five VM tests added; stable untouched.
