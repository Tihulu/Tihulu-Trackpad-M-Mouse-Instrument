# Group MIDI delivery and endpoint identity candidate

Parent #163 exact 557dbd930677fa50b623b128b65b822e2df5d42c; core run 45590215724 passed 471 tests, native job pending at creation. This candidate adds synchronous injected output delivery, not a live CoreMIDI endpoint.

- The existing PatchOutputLedger is configured independently per nonempty group. A failed send retires only the affected router group, stops subsequent commands for that group, and immediately attempts neutral commands for every attempted outstanding destination, including a failed onset. Healthy groups continue; no broad CC reset.
- The ledger is authoritative for wire cleanup; logical panic commands for unattempted targets are not sent. Failed cleanup is retained and retryable only for retired groups; global panic retries all outstanding targets. Successful local send is not proof of DAW receipt or audio. A host must retain the delivery instance and endpoint identities until cleanup is confirmed locally; discarding the instance or process termination cannot guarantee receiver cleanup. No in-place rearm/profile change.
- Endpoint plan uses the full immutable group UUID for the stable name and a versioned deterministic positive Int32 for the candidate CoreMIDI unique ID. A concrete 31-bit collision is tested; a collision fails closed, not silently remapped. Empty groups reserve no ports. Actual CoreMIDI registration must check the system registry and verify the property after setting; concurrent conflicts and partial-open rollback remain native acceptance work.
- New core tests cover failed onset, failed release, failed cleanup retry, skipping unattempted notes, unaffected sibling groups, sustain-only isolation, endpoint rename/archive stability, occupied IDs and a concrete hash collision. Eight tests authored, not yet executed at creation.
- Do not equate an allocated plan with a registered port. The current DAW helper remains read-only; native endpoint allocation, group-port diagnostics, adapter integration, independent MPE and hardware acceptance remain open. Preserve the existing process-wide retained MIDI client. Do not add automatic ports on app start or alter stable.
