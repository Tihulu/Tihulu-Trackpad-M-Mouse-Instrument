# Native event-list regression
Extract the actual CoreMIDI reader used by the bridge into a testable internal function, without changing the packet walk from #123. The macOS-only test creates a real MIDIEventList with three different timestamps and six MIDI1 messages, checks the packet count and exact order. No hardware, DAW, driver, permissions or MIDI endpoint required. The test has been authored, not executed in this environment. Apple documents MIDIEventPacketNext as advancing a pointer belonging to the event list; the implementation no longer calls it on a copied packet. Core tests alone cannot certify this integration. No stable changes.
