# Safe expressive Helper CC domain
Reserve bank selection, data entry, sustain, RPN/NRPN and MIDI channel-mode CCs from arbitrary Helper sliders. Offer 109 expressive CC choices, reject duplicate active vibrato/expression targets, preserve imported values as visibly reserved instead of silently rewriting them. Invalid live proposal stops previous Helper and displays an error; local-only configurations need not validate unsent CCs. Service and compatibility gesture guard input finiteness and CC policy; resets do not emit reserved CCs. Idle bridge stop no longer sends synthetic Helper resets. This does not arbitrate same-channel continuous targets across different instruments; shared destination priority remains a separate design and acceptance gate. Two core tests authored. No stable changes.
