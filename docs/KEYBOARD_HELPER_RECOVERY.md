# External keyboard + MIDI Helper recovery

Observed source-level cause: the same pedal contact entered bend, modulation and contact-size expression aggregation; releasing the contact reset expression to 127, audibly boosting held/sustained external notes. This is a controller change, not a Note On velocity rewrite. Default pedal-assigned surfaces are now excluded from expressive aggregation; an explicit advanced toggle permits sharing. Keyboard Sustain Only configures CC64 without expressive assignments. Use separate surfaces for independent effects. On ordinary lift CC7/11 retain their last intentional values; other momentary effects return to neutral. Explicit Stop/reconfiguration retains the existing owned-controller cleanup, including CC7/11 neutral 127 if previously touched. Custom CCs use target-based neutral rather than assignment-based 127. MIDI input monitoring is not a note-thru path. Existing DAW keyboard input remains separate. Actual DAW acceptance requires checking CC64-only output, held chords, repeated taps, independent expression, and disconnect/reconnect. No stable release modification.
