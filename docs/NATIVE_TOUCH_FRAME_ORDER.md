# Native touch frame order and gain-only updates

Base #151 exact head 472e069954a80593b8d98ecfbe546a77e1ded102. #150 and #151 full CI runs 45532495935 and 45533093571 completed successfully.

Source review found three issues: unknown private callback devices defaulted to Trackpad; contact counts were used for pointer iteration before a bound; and admitted native frames could finish mapping out of order because the state lock was released before mapping. The driver now ignores unknown devices, decodes only 1–32 records with a data pointer, and emits an empty release snapshot for malformed known-device envelopes. Zero-contact snapshots remain releases. The 32-record bound is shared with the Builder mailbox. This validates the envelope, not native pointer lifetime or actual backing allocation. Mapping and committed publication now share the existing service lock; subscriber notifications still occur outside the lock. This addresses overtaking after admission, not callback delivery order before admission. Private ABI, contact states, device classification and render deadlines are unchanged. Multiple external devices of the same logical surface still require explicit identity routing in a future design.

Valid master gain changes no longer invalidate queued musical snapshots or rebuild note mappings. Structural changes and invalid sample domains still invalidate. Gain changes retain the render revision and fence (the existing render plan can reset its tail on revision change). The new critical section may increase lock contention; measure callback-to-main latency and motor timing before claiming any speedup. No physical test, actual DAW dropout reproduction or full native verification performed on this candidate.

Actual isolated evidence: exact NativeTouchFramePolicy.swift Git blob ae0726b597a1af24face58f3223f573a51aecd2f reconstructed and verified via git hash-object, compiled with Swift 6.2.1 Linux -O, 88 assertions passed for unknown devices, malformed/empty envelopes and all valid count values. Two core and one macOS configuration regression tests authored. Full candidate CI pending.
