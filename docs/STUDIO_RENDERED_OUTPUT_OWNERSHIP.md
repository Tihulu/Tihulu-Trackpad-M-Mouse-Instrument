# Legacy rendered/live motor ownership
Rendered Voice, audio/MIDI file, tones and haptic patterns cannot start with active legacy Touch, MIDI bridge, Helper or Tilt. Legacy live starts refuse while a rendered request is active (including asynchronous rendering). Existing combined sequence, shared note and Speaker fences remain unchanged. Dedicated MIDI-only Builder/Sequencer/Chord sessions remain independent. Voice/audio Stop no longer stops the independent MIDI sequencer; global Stop Playback retains its existing broader contract. An idle rendered stop does not call the shared playback engine. If required MIDI bridge startup fails, Touch/Helper no longer report a new successful start. Conservative policy intentionally blocks even MIDI-only legacy Touch/Helper because they use the same legacy bridge and motor path. Pure 32-state regression authored; macOS/physical behavior pending. No stable change.
