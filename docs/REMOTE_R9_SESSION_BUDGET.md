# R9 conservative remote session budget

Reserve five of sixteen router slots for the five currently supported local physical sources, even when not mapped. Admit at most four remote peers and reserve each peer's full mapped stream count (touch, tilt, acceleration including Air Drums, rotation, drums, piano, pedals). A 7-stream peer and 4-stream peer fit; two 7-stream peers do not. Refuse admission atomically after authenticated invitation consumption if insufficient budget, without evicting any existing peer or local owner. Reservation is released only when the peer is removed, including watchdog expiry, disconnect or stop; stream release alone does not free it. This is a deliberately conservative policy, not dynamic per-stream negotiation or proof of sustainable RTT. Existing v1–7 wire format and deadlines unchanged. Admission refusal currently uses existing generic rejection; no detailed refusal metadata. Two regression scenarios added; CI and independent native verification pending.
