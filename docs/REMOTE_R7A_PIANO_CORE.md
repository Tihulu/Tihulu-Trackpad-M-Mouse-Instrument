# R7a — mobile piano host core

Adds 25 logical chromatic keys and one sustain signal, default GM channel 1, notes 48–72 with fixed velocity 100. Authenticated v5 pianoKeys message is a full 26-bit mask (bits 0–24 keys, bit 25 sustain). No client note, channel or velocity fields; only configured bits permitted. Separate peer session and 350 ms freshness independent of drums/touch/motion; idle heartbeat cannot mask a held piano key or pedal. New owners are added before old owners are removed; sustain engages before new notes and releases after old notes. Zero snapshot releases the entire piano session, not other controls. Existing shared ownership means a held note shared by another source is not retriggered or silenced. MIDI sustain behavior depends on receiver.

Host route factory and archive validation; full preset insertion and browser keyboard follow in R7b. Planned two overlapping 13-key views within the 25-key range, octave change only after releasing held keys/pedal, and optional scale highlighting. This does not yet implement arbitrary transpose, pressure, keyboard UI, scale selection or native audio. Four Swift tests cover polyphony, release, sustain timeout and schema/route policy. Stable unchanged; physical acceptance HOLD.
