# R9 v8 mapping wire host

Adds only destination metadata request/response, no labels. Flat exact v8 request, ASCII, canonical page 0...7, common sequence and existing 256-byte cap. Host requires prior accepted v7, idle peer, no prior performance input, one ordered snapshot, >=50ms page spacing, 10s phase ceiling in addition to existing idle/active deadlines. Once first page accepted, only ordered mapping requests until completion. Replays, skips, active, premature, too-fast and post-completion requests revoke. Existing v1–7 clients need not begin v8. Source/consent projection remains #93; default withheld empty page contains no counts. Typed response replaces ordinary ACK on same transport; no additional socket. Existing UI does not advertise v8 or enable consent, so external v8 clients may only receive withheld result on current Mac UI. Host-only API can issue consent for test. No client label or tuple parser yet. Four Swift test scenarios authored, CI/macOS/physical pending. Stable untouched.
