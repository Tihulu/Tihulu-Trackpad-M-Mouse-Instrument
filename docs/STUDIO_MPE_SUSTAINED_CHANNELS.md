# MPE sustained member reservations
Allocate lower-zone member channels 1...15 excluding GM channel 9 (zero based), active note owners, sustained and retired channels. On finger lift under CC64, retire the member until the last pedal owner releases. Preserve its bend while sustained; after CC64 OFF, neutralize retired fretless channels only when no remaining note owner uses them. Never steal on exhaustion. Existing standard mode and dedicated endpoints remain independent. This is a conservative allocator, not a complete MPE zone negotiation implementation. Live configuration changes and fretted note changes within a held contact, channel-wide CC conflicts, and receiver-confirmed delivery remain separate gates. Three core regression scenarios authored. Native MIDI and physical acceptance pending. Stable untouched.
