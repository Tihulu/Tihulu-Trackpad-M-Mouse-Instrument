# R9 unified performance navigation
Play, Setup and Connection share one connection and scheduler. Connection until metadata ready, then Play. Navigation refuses while any control enabled, requested, held, queued, sent or releasing, or any ACK outstanding. Release/disconnect remain sticky and accessible in each view. No forced panel change while playing or auto-rearm. Setup contains existing mapping/workload policy. Responsive two-column tablet layout, existing single-column phone layout. ACK metric is recent median (up to 8 accepted performance/heartbeat frames, stale after 2s), not MIDI/audio latency, reset on close. No additional network traffic.
