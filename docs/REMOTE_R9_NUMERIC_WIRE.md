# R9 numeric wire contract and scanner caching

Caches the immutable compiled regexes without bypassing any transport/runtime/bridge checks. Exact lexical unsigned decimal tokens for version, sequence, mask and manifest integers (no sign, fraction, exponent, or leading zero). Inactive pedal slots require literal 0; active binary slots literal 1. Active continuous values retain JSON number grammar, finite IEEE-754 conversion followed by existing range validation; mathematical values that round to the boundary are accepted by design. UTF-8 BOM rejected explicitly. Existing browser JSON.stringify emits canonical tokens. External clients using 1.0/0.0 for binary or inactive pedals must use integers. Update test serializer accordingly. No changes to safety deadlines, protocol version or byte cap. Prior scanner microbenchmark showed caching benefit; this integrated variant has not been natively benchmarked. 41/41 browser callbacks passed in V8 shim replay; native Swift and Node CI pending. Stable untouched.
