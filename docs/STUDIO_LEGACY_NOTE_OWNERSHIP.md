# Legacy shared-endpoint note ownership
Touch contacts, the single-touch compatibility path and performance notes now share one outgoing note-owner ledger per channel/note. First owner sends note-on, final owner sends note-off. Existing touch note transitions and pitch bend messages remain separate. MIDI-only Touch Bar reuses the existing screen/native key ownership model without local sustain emulation (CC64 is handled by the separate sustain ledger). Bridge shutdown releases remaining owners. Two pure regressions authored. Repeated same-note overlaps intentionally coalesce; this changes retrigger behavior while another owner remains held. Legacy CoreMIDI delivery is best-effort, channel-wide bend/CC and MPE allocation collisions are not solved by this change. Real DAW/native UI verification remains pending. Stable untouched.
