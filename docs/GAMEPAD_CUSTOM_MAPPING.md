# Xbox / extended gamepad custom mapping

In Instrument Builder, select Controller 1 or 2 in the custom control map. Select a button, trigger or stick axis. Assign a MIDI note, chord (1–12 distinct MIDI notes), sustain, bend or permitted CC; sticks accept continuous destinations only. Unmapped removes only the selected control's routes. Advanced Routes remains the editor for mixed destinations and calibration. Each slot keeps independent mappings; total patch limit remains 64 routes. Save/export uses the existing patch archive. No automatic connection or playback.

Pair controllers in macOS, bind distinct devices to slots, release their controls and start explicitly. Select MIDI, Trackpad or both using the two output toggles in Test instrument. With both off, monitor only. MIDI uses the dedicated Builder port. The new local Trackpad output is available for native gamepad-only patches; both slots share the output selection. Mixed device patches still use the existing MIDI path. Local haptics consumes reconciled commands, supports held notes/chords, sustain, ±2 semitone bend and CC7/11; other CCs are DAW-only. Up to six folded audible tones share one actuator. Competing haptic sessions are refused; Stop and failure revoke the scoped renderer. No implicit MIDI feedback loop. Per-controller output splitting and more than two slots are not implemented.

Four new core regression tests cover slot isolation, invalid assignments, overlapping chord ownership/disconnect and haptic safety/sustain/bend. Tests authored, not yet executed on this head. Hardware acceptance: two paired Xbox controllers, overlapping chords and independent MIDI channels, explicit MIDI/Trackpad/Both starts, disconnect while sustained, Stop/Panic, conflicting motor ownership and rapid taps. The existing 20 ms polling adapter can miss very short button presses; event capture is a separate performance gate. No physical verification claimed. Stable untouched.
