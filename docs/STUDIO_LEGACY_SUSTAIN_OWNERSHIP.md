# Legacy shared endpoint sustain ownership
Separate Touch, Helper and MIDI-only Touch Bar CC64 owners, using union per channel. Only first owner sends 127, last owner sends 0; remapping retains unrelated held channels. MPE Touch keeps its existing channel accumulation. Full bridge stop releases all owners in sorted channel order; profile changes release Touch Bar only. No extra network or haptic output. Existing dedicated endpoints unchanged. Three shared-core tests including 768 two-channel transitions authored. CoreMIDI legacy send is still best-effort, not a confirmed delivery ledger; outgoing calls remain serialized by controller, real MIDI monitor acceptance pending. Direct legacy CC, note and pitch ownership outside sustain remain separate work. No stable changes.
