# R9 mapping projection — isolated core foundation

Implements stable 49 logical signal IDs, sorted source-scoped destination tuples and duplicate-target multiplicity, eight rows per page, 64-route bound, 256-byte encoding limit. Only configured phone/tablet routes; no raw patch, route IDs, labels, calibration or local destinations. Host-only invitation parameter defaults false; consumed invitation binds permission to that peer, reissue/expiry/consume clears it. Idle internal page API returns empty withheld result without counts; revoked/active peers cannot read. This is deliberately NOT a wire feature yet: no v8 request parser, sequence/page phase enforcement, transport dispatch, browser negotiation, Mac consent UI or labels. Existing v1–7 wire unchanged; production UI cannot enable details yet. Three Swift tests added; native CI pending. Next implement v8 phase and transport, then consent UI/browser staged validation. Stable unchanged.
