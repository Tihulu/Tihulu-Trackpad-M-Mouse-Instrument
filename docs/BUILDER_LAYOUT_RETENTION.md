# Layout editing retention
Visible layout editing no longer silently drops wholly dormant controls or the original style of unchanged temporary XY/key fallbacks. A partially mapped XY retains its X label on the single-axis slider. Explicit edits to that fallback replace the saved style; explicit Reset layout drops dormant controls with a warning, while Cancel preserves the original. Merge is bounded by the existing 64-widget validity rule; over-capacity fails without changing the patch. Runtime resolution still only offers mapped inputs. Two core tests authored. Native editor acceptance and CI pending; no stable changes.
