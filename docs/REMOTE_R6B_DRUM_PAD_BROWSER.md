# R6b — mobile eight-pad browser interface

Explicit enable after admission, eight named logical buttons with pressed state, two/four-column responsive layout and Release all. Install all eight Mac routes for the selected source with the non-destructive Add missing drum pads action; existing mappings and velocities remain editable. Labels are defaults, not fetched from the host; custom assignments can differ. Host rejects unconfigured active bits and closes the connection. Capability negotiation remains future work.

Multiple pointer owners (including multiple fingers on one pad) share the complete mask. Capture failure, queue overflow (8 transitions), edge age ≥150 ms, socket failure, background/blur or rotation during held pads fail closed. Press/release edges are queued in order rather than replacing a short tap with the latest state. Single outstanding ACK, 25 ms minimum normal pad service interval, 50 ms held refresh, oldest-serviced eligible stream shares the scheduler. Emergency Release all clears unsent edges and sends zero after any outstanding ACK; disabling does the same. Keyboard Space/Enter supported with release on button blur. No pressure inference or background capture. The host keeps its independent 350 ms watchdog. Real throughput, simultaneous Air Drums, phone behavior and DAW response remain HOLD; the bounded queue deliberately drops the connection rather than playing late hits.

Five added VM scenarios for short taps, shared/multiple contacts, release all, held refresh/backlog and lifecycle. Existing browser tests retained. Stable unchanged.
