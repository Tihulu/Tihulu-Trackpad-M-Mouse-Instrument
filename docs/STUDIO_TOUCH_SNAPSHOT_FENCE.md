# Touch snapshot publication fence
Stamp committed snapshots with configuration/activity revision and publication order. Reject older calculations for the same surface before caching; commit native haptic state in the same lock as snapshot publication. The Studio callback checks current service revision and monotonic publication sequence before using it on MainActor. Touch/Helper start, stop and Helper routing changes invalidate queued samples; normal ordered frames are not coalesced. Clears per-surface cached input on revision change. The compatibility callback API remains available. Reordered callbacks are dropped rather than replayed; this can lose an edge under contention and requires native stress acceptance. Does not yet drain an already submitted driver frame or prove no missed release if the device stops sending. Two core tests authored. Stable untouched.
