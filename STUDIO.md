# NoSpeaker Studio

This fork contains the original `nospeaker` project plus an independent downstream macOS workstation in [`studio/`](studio/).

NoSpeaker Studio is based on **nospeaker by Cody Collier (os6)** and preserves the original MIT attribution. The original root CLI source and build scripts remain untouched by the Studio overlay.

## Studio features

- Text-to-haptic Voice
- Physical Touch Instrument
- Note Sequencer
- Drum Sequencer
- CoreMIDI / Logic Pro bridge
- Standard MIDI File import
- Audio drag/drop conversion
- Live system-audio Trackpad Speaker Mode
- Diagnostics and Panic Stop

See [`studio/README.md`](studio/README.md) for build, safety, architecture and attribution details.
