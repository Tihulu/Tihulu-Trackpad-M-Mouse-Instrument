# Instrument Builder P2F — expressive performance widgets

Extends the saved performance layout with a relative-drag knob (holds last position), spring ribbon (releases through existing scoped ownership, not raw zero), and momentary note/chord key. The latter is offered only for inputs whose mapped targets are exclusively note gates and for which one normalized endpoint activates every gate; supports inverted mappings, falls back to a slider when incompatible. Actual mapped pitch names are shown; this is a mapped key, not a full polyphonic keyboard generator. Mouse drag hold/release, gesture cancellation, app deactivation and disappearance release momentary controls; explicit Release and global Stop/Panic remain. Accessible sliders and a keyboard-accessible 150 ms note pulse are available. XY pairing is split explicitly before changing style. All layouts retain existing archive and graph path, no new engine, no hardware activation or new MIDI routes, no mandatory dependency. Three core tests for note/chord gates, incompatible route fallback and archive/graph. Native gesture/cancellation, window focus, DAW and actual hardware acceptance pending. No stable merge.
