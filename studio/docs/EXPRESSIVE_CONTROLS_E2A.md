# Expressive Controls E2a — continuous response

Optional response per continuous CC/bend mapping: independent normalized sweep range, 0–250 ms sample-driven exponential smoothing, optional absolute release position (wire range shown in editor). No timer or background model; first sample immediate, release immediate. Default nil preserves legacy ranges, no smoothing and default neutral. Notes and sustain reject this option. Shared targets must have matching release wire value; source priority remains unchanged. Router and attempted-output ledger use exactly the same release policy, including failed release retry on Stop/Panic. Ledger policy cannot change while any attempted non-neutral or failed state remains. Native lift/loss and simulation disconnect use existing router cleanup. Patchbay compile/reconstruct and JSON preserve settings; same reusable editor in route and graph. New Pan preset returns 64; existing saved patches unchanged. Hold-last, pickup, rate limiting and smoothing trailing samples without input are not implemented. Five core tests cover range, time response, release consistency/retry, conflicts and legacy decode/pan. Actual native sweep/DAW acceptance pending. No stable merge.
