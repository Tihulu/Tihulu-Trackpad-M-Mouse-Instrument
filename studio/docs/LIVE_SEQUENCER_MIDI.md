# Live sequencer MIDI

Adds explicit Trackpad (existing default), MIDI, Both choices for note and drum sequencers; workspace optional fields preserve old archives. MIDI uses a dedicated process-lifetime isolated virtual source TIHULU Sequencer, independent of haptic hardware; melody channel 1, GM drums channel 10. One live MIDI sequence at a time. Snapshot validated groove clip and tempo, absolute monotonic note scheduling, off-before-on ordering, skip expired onsets, bounded cycle recovery. Record attempted Note Ons before send, release only owned notes, keep failed release ledger for Stop/Panic retry. Navigation does not stop the session; global Stop/Panic and reconnect do. Both starts the existing haptic timeline and MIDI schedule separately, reserves motor against new conflicting modes, stops both on explicit stop or haptic failure; alignment is experimental and not sample-accurate. Motor may limit duration/polyphony. No external DAW clock, simultaneous independent note/drum tracks, per-note MPE or claimed receiver acknowledgement. Core tests cover schedule ordering and physical-send ledger failure/cleanup. Native tests needed: route source to Logic, verify channel mapping, repeated start/stop and Panic, loop/rest, no motor in MIDI-only, Both alignment, audio-device change and source isolation. No stable release.
