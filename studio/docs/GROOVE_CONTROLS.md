# Expressive groove controls

Optional workspace-persisted settings in note and drum sequencers: sixteenth swing 50–75, bounded deterministic timing/velocity humanization, intensity scaling, beat accent, probability and seed. Source grid is unchanged. Both haptic Play (when enabled) and standard MIDI export resolve the same take. Probability preserves grid-zero hits if present and may reject an otherwise empty take; no hidden notes added. A new seed changes the take; loops repeat it. Gate is shortened when necessary to avoid identical-note overlaps and preserve the full clip boundary. Old workspace archives decode with groove nil and use the previous playback path. No automatic playback, network or model. Haptic drum profiles remain distinct from MIDI durations and motor safety may limit duration/frequency; no claim of matching synth sound. No live MIDI yet. Four tests cover identity, swing, overlap, determinism, export/preview onset parity and invalid inputs. Native physical and DAW acceptance pending. Stable untouched.
