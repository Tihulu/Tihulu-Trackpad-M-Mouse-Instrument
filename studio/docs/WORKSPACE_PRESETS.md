# Workspace presets — first increment

Five quick setup templates prepare existing instrument/helper draft settings without starting audio, MIDI, capture or sensor sessions. User confirms replacement of instrument/helper settings; sequencer patterns survive. Save/Load Workspace uses a bounded, versioned local JSON envelope with strict ranges and shape validation. Includes touch/helper draft, note/drum patterns, tempo and Magic Mouse orientation. Excludes voice text, media, permissions, shortcuts, device addresses, and active state. Loading is explicit, confirmed and gated on idle sessions (including bridge, capture and hinge). It is not the future general-purpose patch graph or a full project format.

Acceptance: prepare each template and verify actual routing before Start, then start the other surface separately; check reverse roles and GM notes. Save non-default settings and patterns, change them, load and compare. Test malformed, oversized, foreign-version files; reject without partial state change. Cancel dialogs and test active-session guard. No automatic playback, capture, permissions or network activity on load. Native Mac dialogs and visual verification pending.
