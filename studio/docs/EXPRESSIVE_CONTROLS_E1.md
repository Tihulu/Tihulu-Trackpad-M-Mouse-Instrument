# Expressive Controls E1 — reusable preset catalog

One optional disclosure in the existing Builder adds Wah CC4, Cutoff CC74, Whammy pitch bend, Expression CC11, Volume CC7, Vibrato CC1, Pan CC10 and XY cutoff/resonance CC74/71 to the editable draft. Appends only, refuses occupied MIDI targets, invalid channels or unsupported combinations, preserves existing routes and archive schema. No autoplay or replacement of existing settings. Physical Trackpad/external touch mode uses the existing adapter; Touch Bar, lid, phone/tablet and camera are explicitly simulation-only for the Builder catalog even where legacy standalone controls exist. Generic normalized angle/speed/gesture are not real motion adapters. Current router release defaults are unchanged (CC7/11=127, bend=8192, other CC=0); pan's zero release caveat is explicit and configurable release/range belongs to E2. First owned continuous sample now transmits even at neutral so the DAW need not already match the router. No repeated identical sample or gate behavior change. Four tests cover first neutral, physical runtime sweep/release, append/roundtrip/conflict, XY and simulation-only inputs. DAW MIDI Learn is performed on receiver, not implemented in app yet. Actual native sweep and plug-in assignment tests required; no physical PASS. Next: per-target release and output range, then custom performance layout and adapter integration. Stable untouched.
