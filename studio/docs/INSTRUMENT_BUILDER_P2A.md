# Instrument Builder P2a — saved patches and testable MIDI

Replaces the Mapping Lab entry with a real declarative editor, using the existing SensorRouter rather than building a second mapping engine. Blank or expressive starter, up to 64 routes, source/signal, note/CC/bend/sustain, channel, calibration, inversion, dead zone, exponent, threshold/hysteresis, priority and velocity. Explicit local save, versioned bounded JSON import/export, rejects reserved CC configuration and invalid or duplicate routes. No executable data, no auto-start. Simulated source sessions share ownership across routes; one slider per source/signal, scoped disconnect, command monitor. Explicit optional dedicated TIHULU Instrument Builder virtual MIDI source. Attempted output ledger retains failed releases, note-offs before neutral controls on Stop/Panic; page disappearance stops test. No hardware adapters, remote server, haptic graph or camera permission yet. Simulated inputs are explicitly labeled. Actual DAW receiver must be separate from other source routes. Three core tests for archive, ownership and failed sends. Next: shared native touch input, timed watchdog, hardware capability and calibration; then typed graph and mobile layout. No stable merge.
