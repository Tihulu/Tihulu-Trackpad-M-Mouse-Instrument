# Custom scale and intonation editor — first increment

Custom octave-repeating scale with 2–12 distinct nominal semitone degrees, root fixed, root-relative integer cent offsets ±49 per selected non-root degree. User names and local chord-bank archive; existing built-in scales and custom absolute MIDI chord slots remain. Generated chord stacks, progression and arpeggiator use the same bank. Haptic rendering applies per-pitch-class offsets before octave folding and preserves the six-tone/safety limits. Off-scale custom chord pitch classes remain equal-tempered unless a selected degree supplies that class. Built-in chord names describe nominal voicing.

This is a useful restricted microtonal editor, not arbitrary EDO, multiple notes within one MIDI semitone, authentic makam seyir, MPE, MIDI Tuning Standard or external synth retuning. Nonzero tuning blocks MIDI/Both arming unless the user explicitly allows the 12-TET MIDI approximation. In Both, only the haptic route uses custom cents. No accidental channel-wide bend. No changes to Touch Instrument, Touch Bar lead notes or existing scale archives in this increment; later shared tuning adapters should support those separately. Settings editable only disarmed. No auto-arm. Four core tests for generation, per-tone frequency, bounds, output gate, old archive, arpeggio and octave folding. Native acceptance: edit/reset, all output combinations, custom chords, shared note output, physical pitch audibility and old bank restore. No stable release.
