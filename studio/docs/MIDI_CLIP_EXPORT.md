# Editable symbolic clip and DAW export

First implementation step of the approved music AI/GPU roadmap. Introduces a Codable model-neutral bounded MIDIClip (960 PPQ, tempo, duration, note timing, pitch, velocity, channel). This is a symbolic data contract, not a complete AI job API. Validates finite tempo, lengths and note ranges, overlap of identical channel/pitch, and bounded count; no script, SysEx, automatic playback or network. Standard MIDI File format 0, tempo meta event, deterministic Note Off before Note On at coincident ticks, End of Track includes trailing rests. Native save panel and error reporting in Note Sequencer, Drum Sequencer and Chord Progression (includes arpeggio). Export one cycle irrespective of loop. Drum notes are GM channel 10. Chord export uses nominal note pitches and selected bank channel, not MPE or cent offsets; explicitly labeled for microtonal bank. Current live playback unchanged. Import .mid into Logic or another DAW and assign instrument. Existing parser reads notes but currently does not include trailing End of Track rests in its duration; file writer does preserve the boundary, tested in raw bytes. Four core tests for round-trip notes, drums, arpeggio/rest and malformed clip rejection. Actual Logic import and UI acceptance pending.

Next: richer phrase editor and live sequencer MIDI transport; AI job contract and policy, isolated optional local models and authenticated home GPU, then optional cloud. Keep Builder and hardware reliability independent; no mandatory AI, no stable release until native acceptance.
