# Shared custom scale — Touch Instrument

Explicit session-local copy of the current chord-bank scale (built-in or custom), no automatic retuning when the bank changes. Uses the existing Touch root, width and surface routes. Fretted regions use the shared scale's selected degrees and haptic frequency uses root-relative cent offsets. Built-in Touch scales unchanged; fretless remains continuous and ignores custom tuning. GM drum mapping and MIDI untouched. Microtonal fretted melodic MIDI route requires explicit equal-tempered approximation in the copied scale. No channel-wide pitch bend or false MPE tuning claim. Drum-only MIDI is unaffected. Stop before copying or clearing; settings do not auto-arm. Copy is not persisted into existing workspace archives in this increment; the bank itself remains persisted. Two core and one macOS configuration tests cover width, root, bounds, tuning, fretted/fretless and drum MIDI gate. Physical pitch, touch position mapping, both surfaces, route combinations and existing workspace behavior still require native acceptance. True per-note MIDI tuning remains separate. No stable release.
