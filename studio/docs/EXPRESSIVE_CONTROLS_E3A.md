# Expressive Controls E3a — native lid and Builder ribbon

Optional explicit Native inputs mode accepts existing touch surfaces, lid angle and dedicated Touch Bar X ribbon routes in the same PhysicalPatchRuntime/SensorRouter; independent scoped releases and configured release values. Read-only existing hinge adapter polled at 10 Hz, normalized 5–175 degrees then calibrated by route, no forced hinge movements. Builder fails closed if lid adapter is not available or independent tilt already active; independent tilt cannot start while Builder owns it. No implicit legacy MIDI output. Native Touch Bar adds a distinct ribbon only while a Builder session requests it; session-token callback fences old controls, native mouse release and on-screen fallback release, 350 ms watchdog for inactive samples (even held still), no automatic Touch Bar presence claim. No other native zone replaced. Lid-only/ribbon-only sessions do not require haptic engine or start touch monitor. Camera/phone remain simulated. Three core tests for shared scalar ownership, normalization and stale stop. Physical detection, native Touch Bar event delivery, focus/sleep and DAW tests pending. No stable merge.
