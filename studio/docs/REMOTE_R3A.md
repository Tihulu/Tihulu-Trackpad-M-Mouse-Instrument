Static HTML and JS embedded in binary; no external scripts, arbitrary files, uploads, query secrets or persistence. Browser single-pointer XY uses normalized Y-up axes, one outstanding host acknowledgment, 50 ms active refresh plus idle heartbeat, release prioritized after pending acknowledgment, close on timeout/error/backlog/blur/pagehide/hidden.
