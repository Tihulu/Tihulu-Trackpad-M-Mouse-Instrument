# Instrument Builder P2B — native surface adapter

Experimental, explicit physical mode for patches containing only Trackpad or compatible external touch surface routes and X/Y/contact/contact size. Uses existing private driver (requires existing engine initialization), exclusive native monitor while Builder test is open; not a second simultaneous registration. Existing Touch/Helper monitoring must be stopped first. External device classification is inherited and may include non-Magic-Mouse devices. No fake force, no multi-finger ownership; lowest current contact ID drives each source kind. Empty/invalid frame disconnects source, 350 ms local receipt watchdog releases lost contacts, 64-frame per-run FIFO with fail-closed overflow/stale backlog; 20 ms polling on main actor, no MIDI work in private callback, no automatic pointer capture. Device data not persisted. Explicit Stop/Panic, page departure, failed MIDI and reconnect stop monitoring and drain owned controls. Other sources stay simulated. No claim of hardware compatibility or latency; test actual empty-frame behavior, disconnect/sleep/wake, orientation, mixed source releases and CPU/jitter on M2. Two core tests plus mailbox test. Next shared monitor integration for concurrent live Builder and Touch/Helper, richer capability/identity, haptic destinations, typed graph. Stable unchanged.
