# Q2d — Opt-in shared chord and Touch Bar output

The corrected Q2b and Q2c-pre core/PR macOS checks passed before this increment. This is the first limited production-path adapter, not a general mixer release. The shared note output setting is session-only, OFF by default, editable only while both haptic outputs are disarmed, reset by Panic/reconnect. Existing solo output path remains intact. When enabled, both Chord Pads and Touch Bar Trackpad/Both use one SharedLiveNoteOutput with one 12 ms scheduler, 18 ms bounded slices, existing six-tone cap and synchronous coordinator sink. No timer when both sources are silent; latest held-note intent per source; explicit clear/release and retirement. Failure notifies both armed sources and controller releases their associated MIDI state. Detect nil actuation creation as an error; the private API actuation return code is not interpreted as proof of audible output.

Legacy Touch Instrument, incoming MIDI, sequencers, voice and Speaker remain exclusive with the optional note outputs. Existing separate MIDI endpoints and full MIDI voicing are unchanged. Use dedicated DAW tracks/channels. To play together, enable the setting before arming, arm both outputs and use the chord strip beside Touch Bar or the native controls. Source release does not release another source. Existing UI focus/page release rules still apply. No device support or acoustic quality claims.

Three Mac mock integration tests cover held-note refresh, scoped release, idle, retirement, sink failure and source validation. Actual hardware acceptance: solo A/B, chord + piano simultaneously, shared frequencies and six-note budget, latch and sustain, stop each independently, Panic and rapid rearm, no timer writes while silent, failure/disconnect, MIDI Both on dedicated channels, regression against all legacy modes. Measure latency, tick gaps, CPU and physical sound. No stable publication or default enablement before physical acceptance. Continue useful feature development on separate gated changes, not placeholder implementations.
