# Instrument Builder P2E — performance layouts

Optional saved data-only layout on InstrumentPatch, old JSON remains compatible. Existing mapped signals become native on-screen sliders, pedal-style position controls, 150 ms tap pads or paired X/Y surfaces. Labels, order and full-width cards are editable in a sheet; no duplicate input ownership, no new MIDI routes. Newly mapped signals get default sliders; unassigned saved widgets are dormant until reassigned (opening layout editor resolves current inputs). Graph compile preserves layout. UI uses the existing simulation path and optional dedicated real MIDI source. Physical mode stays distinct; no mixing simulated and physical sessions yet. XY and pedal hold their position until explicit Release/Stop; a pedal is a slider with position display, not a physical force sensor. Tap pads send normalized 1 for 150 ms and remove only their input's contribution, honoring existing gate/inversion configuration; inverted gates may require a slider instead. Repeated taps retrigger via scoped release and cancel previous timer; Stop/Panic/disconnect cancel tasks. XY has keyboard/VoiceOver sliders. No autoplay, new dependencies, freeform drag/resize canvas, knob or piano keyboard yet. Three core tests cover archive/graph preservation, XY pairing and release ownership. Physical and native UI/DAW acceptance pending. Stable untouched.
