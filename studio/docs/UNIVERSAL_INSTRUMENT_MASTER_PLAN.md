# TIHULU Universal Instrument Studio — Master development plan

Status: design and development backlog, not a claim that all features are implemented. Existing app and repository name remain Tihulu Trackpad & M. Mouse Instrument. User communication in Turkish; repository, UI and code in English, except the approved Turkish spoken greeting. Based on os6/nospeaker (Cody Collier, MIT). Preserve attribution and third-party licenses.

## 1. Product vision
A local-first, modular musical environment that lets musicians invent new instruments from their available hardware, not merely use a catalog of presets. Native macOS remains the host. Trackpad, Magic Mouse, Touch Bar, lid angle, camera, microphone, phones, tablets and external MIDI/OSC controllers are independent optional sources. Hardware availability is detected, never assumed. UI navigation never owns a running session. The same engine supports a simple ready-to-play mode and an advanced instrument builder; all idle modules stay off.

## 3. Architecture
Source adapters -> typed timestamped events -> session manager -> calibration/filtering -> gesture/rule engine -> patch graph and instrument modules -> note/CC ownership and output arbitration -> CoreMIDI/MPE, local audio, safe haptics or OSC. Separate control, render and UI queues. No blocking or expensive work in CGEvent callbacks. Coalesce continuous events, never silently discard Note Off. Reference-count overlapping notes, sustain owners and controller leases; release only departing source's notes, except explicit global Panic. Channel conflicts are visible, configurable and tested. Haptic actuator shared by a central bounded scheduler; no increase to existing motor safety limits. Resource arbitration across speaker, voice, sequencers and instrument modes. Measure latency p50/p95, queue depth, drops, input age, CPU/memory and thermal behavior; no invented performance claims.

## 4. TIHULU Builder / Patch (central product)
- Simple editor: pick a source, input parameter, destination, channel, scale, curve, threshold and release behavior. MIDI Learn, live monitor, guided calibration, per-source capability badges, templates.
- Advanced visual patchbay: typed nodes/ports and validated connections. Sources: coordinates, touch lifecycle, contact size vs verified pressure, gestures, motion/orientation, angle/speed/direction, audio features, MIDI/OSC, clock. Processors: quantizer, scale/microtuning, transpose, chord generator, envelope, LFO, gate, sample/hold, dead zone, smoothing, hysteresis, remap, curves, inversion, multiplier, mixer, delay, arpeggiator, probability, Euclidean rhythm, logic, state machine and conditional routing.
- Rules: IF/THEN/AND/OR, gesture plus contact, modifiers, layers, toggles, thresholds and timers; edge-trigger vs held. Deterministic conflict strategies: priority, override, additive, multiply, weighted blend; clamp all outputs.
- Examples: trackpad held + camera pinch -> bend; same pinch with no contact -> cutoff; Touch Bar modifier + phone motion -> scene morph; loss of source -> scoped release.
- Custom layouts: draggable/resizable zones, widgets (piano, pad, fretboard, ribbon, knob, slider, XY, transport, sequence), horizontal/vertical orientation, multiple pages and macros. Source role is independent of UI. Save/import/export versioned declarative JSON presets, validate types/ranges/cycles and size, no arbitrary executable code. Undo/redo, clone, reset, safe preview, instrument library and optional offline sharing. Human-readable provenance, capability fallbacks and compatibility warnings. Native host and mobile use same schema.
- Acceptance: create original instrument from blank project, combine two or more sources, save/reopen, export/import without losing mappings, deterministic replay, invalid graph rejection, no stuck notes or runaway loops, simulator vs hardware accurately labeled.

## 5. TIHULU Touch (Trackpad & Magic Mouse)
Keep existing fretted/fretless 0.50x–2.00x size range, MIDI/haptic/both output, independent sessions, optional Global Capture with recorded shortcut and reliable Esc/Panic release. Magic Mouse horizontal/vertical transform shared across every feature. Both surfaces can independently play or control. Trackpad and Magic Mouse physical capabilities differ: contact size is not force; finger identity is not guaranteed; external mouse motion must be verified.
- Piano, guitar/bass, violin/bow, fretless oud, baglama, kanun, flute/harmonica, handpan, tabla, GM drums (8/12/16 pads and 2D layout), chord strumming, isomorphic grid, MPE per-contact pitch/expression, scale lock, haptic fret boundaries, virtual faders/XY, octave navigator, scratch, ratchet, rhythmic shaker, finger zones/orchestra.
- Orbit, granular playground, gravity synth, elastic strings, magnetic/ghost notes, wave/rhythm painter, gesture looper, water/particle simulation and finger billiards. Local synth or DAW provides advanced audio; do not imply a single haptic motor reproduces polyphonic hi-fi sound.
- Drum parity with sequencer's six base voices, distinct additional GM profiles, correct MIDI channel 10, velocity, contact-edge trigger, simultaneous hits, no unintended sustain, physical audition and unchanged sequencer regression.

## 6. TIHULU Bar & Gravity
Native NSTouchBar on supported Macs; on-screen or remote fallback. Fretted piano, continuous ribbon, sustain hold/toggle, bend, vibrato, expression, CC, modulation, filter, volume. Custom order, widths, pages, assignable channels, macros, presets, independent sessions. Advanced: chord memory/strummer, arpeggiator, note repeat/roll, step and Euclidean/probability sequencer, polyrhythm, ADSR/LFO/waveform, sample slicer, transport/loop/overdub/undo, automation painter, snapshot/harmonic morph, orchestral articulation and MIDI Learn.
Lid: read-only opt-in capability probe, manual simulator, calibrate neutral and range, sensitivity/dead zone/smoothing/invert, response curves, angle zones, velocity/direction if sample quality supports them. Map to wah, whammy, filter, expression, volume, modulation, vibrato depth, reverb/delay, crossfade, Leslie, tape speed, scrub, freeze, spatial pan, synth/scene morph, octave/arpeggio, orchestra dynamics, physics gravity. No forced or repeated hard hinge movement, no interference with sleep/lid handling. Unsupported hardware must disable live sensor, not simulate falsely.

## 7. TIHULU Air & Voice
Native AVFoundation + Apple Vision as first camera path; optional MediaPipe if justified. Local hand landmarks, confidence, left/right identity, smoothing, pinch/open/close/rotation/motion, lost-hand release, configurable camera including supported Continuity Camera. Start with Air Theremin, Air MIDI Helper, Air Knobs, Air Drums and Air Piano; then Air Guitar/Violin/Harp/Kanun, conductor, hand shape, gesture drawing/composer, air DJ, body/head/facial controllers, two-person jam, color/object/visual card sequencer, motion field, AR where supported. Monocular estimates are not true depth or force. Opt-in camera/mic, no default recording or upload. Respect bystander privacy.
Voice: installed macOS voices plus optional licensed local Piper model discovery, truthful gender/availability, preview and explicit downloads only, retain actual IDs; display Yelda as Tihulu. Turkish greeting exactly specified by the user in the single startupGreeting source constant; once per process launch, no repeat on navigation or reconnect, cancel on manual action or Stop/Panic. Microphone: hum/whistle-to-MIDI, beatbox, breath/volume, mouth wah, call-and-response, vocal looper, acoustic triggers, voice morph. Audio device changes cannot tear down CoreMIDI.

## 8. TIHULU Speaker 2.0
Defects observed in source: Voice profile currently chooses dominant spectral peaks rather than using LPC/formants; live callback processes each packet separately, drops events beyond 12 and ignores event timestamps; per-packet normalization alters dynamics. Plan continuous bounded PCM ring buffer, sample rate conversion, speech-aware LPC/formant and consonant/pitch features adapted to streaming, stable gain/noise gate, timestamped scheduling and lag/underrun telemetry. Default speech-focused option; preserve legacy profiles for A/B. Profiles: Speech Clarity, Speech Enhanced, Natural Voice, Melody, Rhythm, Full Mix, Experimental; optional noise reduction/AGC and adjustable buffering. Later optional local voice isolation only if needed. Compare same Turkish/English/German spoken clips using old/new paths, physical blind word recognition and timing, background music, silence, no clipping, latency, Stop/Panic and sustained sessions. Never promise loudspeaker fidelity. Separate audio-file and live capture regression. Correct UI state on capture failure and stop; no stale motor playback.

## 9. TIHULU Remote / Jam
Mac-hosted local server OFF by default. QR/code pairing via user-selected LAN interface, no account/internet/port forwarding. Show current generated address without persisting IPs in repository. HTTP touch-only option with clear trusted-LAN warning; trusted local HTTPS/WSS for sensor permissions and encrypted control, no bypass of browser security. Phone browser/PWA for iOS/Android/iPad; WebSocket typed events -> Mac CoreMIDI; do not rely on Web MIDI in Safari. Capability negotiation and permissions per device; graceful fallback. Optional native mobile later for deeper sensors, haptics, AR, Bluetooth/network MIDI and OS-limited background operation.
- Responsive vertical controls and horizontal instruments, tablet multi-panel mode, customizable layout builder and MIDI Learn, per-client channel/device role.
- Touch: piano, fretless ribbon, guitar/baglama, launchpad 16/32/64, drum machine, mixing console, XY/Kaoss, chords, step sequencer, looper, DJ decks, samples, Touch Bar XL, waveform/automation painter, microtonal keyboard, patch editor and live monitor (tempo, MIDI messages, chords, notes, transport, meters, optional score/lyrics). Touch interactions must support real multi-touch/pointercancel/release, not decorative mockups.
- Motion: roll/pitch/yaw, acceleration and speed with calibration; Theremin (angle/gesture, not absolute height), air bow/drumstick, maracas, whammy, wah, spatial synth, approximate trombone slide, conductor, arpeggiator, gesture switch, magic wand. Never encourage throwing devices or unreliable absolute displacement.
- Phone camera/mic: local landmarks, body/face, colors/objects, visual sequencer, breath/voice/beatbox, pocket sampler, motion recording, native AR/depth where available. Transmit only derived events by default, raw media only with distinct explicit opt-in. Browser secure-context/permission/feature checks for camera/mic/motion; iOS web vibration limitations; no silent native-only promises.
- Jam: Host, Musician, Producer, Conductor, Audience, Observer roles with server-enforced scopes. Multiple clients with per-device note ownership and channel reservations; conductor clock, audience aggregated bounded controls. Authentication by expiring single-use pairing code and revocable scoped tokens, rate/size/concurrency limits, strict schema validation, origin checks, no arbitrary host command execution, no cloud, no LAN discovery without consent. Heartbeat, disconnect/tab-hidden/pointercancel releases, stale packet drop, timestamp/sequence validation, reconnect without note replay, optional jitter compensation. Host Panic always available; remote global Panic limited to authorized roles. Measure p95 and jitter with real phones. No persistent network address logging by default.

## 10. TIHULU Anatolia, Motion, Orchestra and Lab

## 13. Milestones and gates (targets, not release promises)
P0 / v0.3.0 preview: integrate and validate existing PRs, icon assets, real-Mac capture and CoreMIDI recovery, drums, persistent sessions, orientation, Turkish greeting/voices, basic Touch Bar and tilt. Preview artifact separate identifier/version; stable assets unchanged. CI + physical acceptance before release.
P1 / v0.3.1: Speaker 2.0 streaming and offline A/B.
P2 / v0.4: universal typed sensor/session/output core and basic Builder, Camera Air MIDI and native hand tracking. This shared foundation precedes further expansion.
P3 / v0.5: Remote LAN touch controller and authenticated server, phone/tablet layout, movement with HTTPS capabilities, then multi-client Jam.
P4 / v0.6: advanced patchbay, rules, presets, motion recording, Touch Bar/tilt modules, Anatolia, microphone and mobile camera features.
P5 / v0.7+: advanced local synth/audio, AR/native mobile optional, generative Lab and interoperability.
P6 / v1.0: validated integrated platform, polished accessibility, rollback/install/uninstall, reproducible artifacts, full documentation. Versions may be adjusted based on measured readiness.
