# Dedicated chord MPE tuning — experimental

An explicitly enabled, isolated CoreMIDI source TIHULU Chord MPE for Chord Pads, Progression and Arpeggiator. Standard MIDI source and Touch Instrument routes unchanged. Lower zone manager channel 1, members 2–16; configure using RPN 6, then RPN 0 +/-2 semitones and centered bends. Each held logical note gets an independent member channel, pitch bend precedes Note On; no global bend or note stealing. A reused channel is initialized before its next note; leave the release-tail bend unchanged. A 16th concurrent note fails closed and stops the chord session. The existing chord refcounts deduplicate overlapping logical notes. The controller tracks actual attempted member-channel notes and retries Note Off on failure; allocator clears only after successful release. No MPE receiver discovery/acknowledgement. Use a dedicated MPE-enabled instrument and matching bend range, not a GM percussion receiver, and re-arm after receiver changes. MPE receiver release tails may be affected by channel reuse; physical/DAW acceptance required. No claim of automatic Logic configuration or true makam seyir. Touch Instrument custom cents remain haptic or explicit 12-TET approximation. Settings backward-compatible and opt-in; no automatic output. Four pure tests for independent bend values, scoped releases, reuse, capacity, setup and archive. Reference: MIDI Polyphonic Expression 1.0, MIDI Manufacturers Association, March 2018, https://d30pueezughrda.cloudfront.net/campaigns/mpe/mpespec.pdf . No stable release.
