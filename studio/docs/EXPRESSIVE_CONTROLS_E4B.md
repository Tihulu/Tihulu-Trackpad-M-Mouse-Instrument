# Expressive Controls E4b — playable single-hand presets and calibration

Additive Air Theremin (fixed root with pinch gate, X pitch bend, Y expression), Pinch Note and Air Wah templates append existing routes and reject occupied targets. Pinch uses inverted aperture and hysteresis; release removes note on open/loss. Continuous axes remain mapped while hand is visible, independent of gate; receiver must have matching bend range and dedicated channel/monophonic synth. This is not full chromatic tracking, a local synthesizer or physical theremin simulation. Manual two-point camera calibration in the existing Builder: start native test with MIDI OFF, choose mapped axis, capture two comfortable endpoints, stop, apply to draft; 5% minimum separation, preserves inversion/curve/gate and other axes. No recording, raw video or auto-output, no new sensor path. Three deterministic core tests for pinch hysteresis/loss, calibration and conflict/roundtrip. Hardware, tracking comfort, latency and DAW acceptance still pending. Next camera selection/orientation and robust tracking lifecycle before remote LAN controller. Stable unchanged.
