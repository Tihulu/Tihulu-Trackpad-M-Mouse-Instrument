# Chord progression

A real editor integrated in the full Chord Pads page; compact chord strip can stop a running progression. 1–16 editable bank-slot references or rests, 1/2/4 beats per step, 10–100% gate, loop or one-shot. Uses global BPM (20–300, snapshot at start), bank velocity/channel/output and custom/generated voicings. Locally persisted validated settings, no automatic arm or playback. A plan resolves the current bank once and shares the musical duration helper from Q4a.

Explicit arm required. Existing ChordPadState, MIDI delivery/cleanup and live-note haptic output are reused. Trackpad/MIDI/Both obey existing motor reservation and shared-note experimental restrictions. Manual pad press stops progression before takeover. Progression persists during page navigation, stops on global focus loss, Release All, disarm, Panic, reconnect or output failure. The same token cancels late callbacks. Monotonic per-step onset and gate deadlines, expired gates skipped, trailing rests preserved; no external MIDI clock or sample-accurate claim. No new device dependency. Haptic six-tone budget still applies, MIDI retains all notes. Makam-inspired banks remain 12-TET.

Four core tests validate timing/rests, custom bank, invalid data, archive, scale changes and full MIDI versus bounded haptic. Controller/clock path requires native acceptance, including all three outputs, shared Touch Bar accompaniment, repeated steps, focus/navigation, rapid manual takeover, Loop/Stop/Panic, saved state and separate DAW routes. No stable merge. Q3 and physical acceptance remain open.
