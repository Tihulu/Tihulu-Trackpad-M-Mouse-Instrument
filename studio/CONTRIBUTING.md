# Contributing

NoSpeaker Studio is an MIT-licensed downstream project based on `os6/nospeaker` by Cody Collier.

## Rules

1. Keep all repository content and user-facing application text in English.
2. Preserve `LICENSE`, `NOTICE` and `ATTRIBUTION.md`.
3. Do not remove or obscure upstream credit.
4. Never raise the haptic motor level above the upstream normal maximum.
5. Keep **PANIC STOP** functional across every playback source.
6. Do not claim a Mac model or macOS version is supported without hardware evidence.
7. Treat `MultitouchSupport` as private, undocumented and breakable.
8. Prefer shared `NoSpeakerCore` transformations so Voice, MIDI, files and Speaker Mode use consistent safety behavior.

Run `./scripts/verify.sh` before opening a pull request.
