# Attribution

NoSpeaker Studio is based on **nospeaker** by **Cody Collier (os6)**:

- Upstream repository: https://github.com/os6/nospeaker
- Upstream release used as the initial compatibility baseline: `v1.0`
- Baseline commit: `64c5fbf493fab0a79382c8e101de8d80083b0d5c`
- Upstream license: MIT

The original project demonstrated audible voice, tones, rhythm, and touch-controlled pitch using a Mac Force Touch trackpad's haptic motor through Apple's private `MultitouchSupport` framework.

## What we keep from upstream

The project intentionally preserves upstream attribution and the original MIT license. The upstream command-line behavior is treated as a compatibility target and should remain available as Studio evolves.

## What NoSpeaker Studio adds

NoSpeaker Studio is an independent extension layer adding a native macOS GUI and separately selectable modes for text/voice, touch performance, note sequencing, drum sequencing, MIDI/Logic integration, dropped audio/MIDI files, and experimental trackpad-speaker workflows.

NoSpeaker Studio is not presented as an Apple product, and the upstream author is not implied to endorse downstream modifications.
